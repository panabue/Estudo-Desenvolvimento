# Missão: Prisma ORM + PostgreSQL

## Por quê
Construir o back-end de projetos pessoais com um banco PostgreSQL bem estruturado e limpo, modelado e acessado via Prisma, sem depender de outra pessoa para a camada de dados. Hoje sou frontend: TypeScript forte, Node.js fraco e quase nada de banco.

## Sucesso é
- Modelar o domínio de um projeto pessoal num contrato Prisma, com chaves, tipos e relações bem escolhidos, e justificar cada escolha.
- Ler e escrever o SQL básico que o Prisma gera (CREATE TABLE, SELECT com JOIN) para entender o que acontece no banco.
- Evoluir o banco com migrations sem perder dados.
- Fazer CRUD e consultas com relações usando o client tipado do Prisma num script Node.js local.
- Reconhecer um schema mal estruturado (dados duplicados, tipo errado, chave fraca) e corrigi-lo.

## Restrições
- Sem prazo nem horário fixo: um pouco por dia, então as lições precisam ser curtas.
- Lições em português, código em inglês.
- Aprender no navegador primeiro e depois praticar em código local.
- PostgreSQL, sem framework por enquanto (Node.js puro).

## Fora do escopo (por ora)
- Frameworks (Next.js, NestJS, Express).
- MongoDB, MySQL e outros bancos.
- Deploy e infraestrutura de produção.
