# Exercícios

Histórico das práticas do módulo Prisma. Cada pasta corresponde a uma lição (mesma numeração de `lessons/`).

- `NNNN-<lição>/`: exercícios daquela lição (arquivos `.prisma`, `.sql`, `.ts`).
- `playground/`: (a partir da lição 2) um único projeto Node.js com Prisma + PostgreSQL que cresce ao longo das lições.

Não versione segredos: a URL do banco fica no `.env`, que está no `.gitignore`.
