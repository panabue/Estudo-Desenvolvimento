# Ponto de partida: TS forte, Node fraco, banco quase zero

O aluno é desenvolvedor frontend com ótimo domínio de TypeScript, pouca noção de Node.js e quase nenhum conhecimento de bancos de dados (declarado pelo próprio aluno na sessão 1).

**Implicações:** não reensinar tipos, generics ou unions. Usar o TypeScript como ponte (model ≈ interface). Ensinar conceitos relacionais do zero (tabela, linha, chave primária, chave estrangeira, normalização) antes ou junto com cada recurso do Prisma. Explicar o tooling do Node (npm, npx, package.json, ESM) quando surgir na prática local.
