# Domina models com campos escalares

Escreve um model do v8 sozinho e sem erro: `// use prisma-8`, `@id @default(autoincrement())`, `?`, `@unique`, `@default(now())`, e escolhe `String` para identificadores como CNPJ. Não é preciso reensinar a sintaxe básica: as próximas lições podem partir daí.

**Evidência:** `exercises/0001-do-model-a-tabela/book.prisma` atendeu a todos os requisitos (2026-11-13).
