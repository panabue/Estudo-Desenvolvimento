Sintaxe do contrato

Cola rápida para escrever contract.prisma. Fonte: Prisma Docs: PSL syntax.

Anatomia

// use prisma-8                      ← obrigatório na 1ª linha

model User {                          ← tabela "User"
  id        Int      @id @default(autoincrement())
  email     String   @unique
  name      String?                     ← ? = aceita NULL
  createdAt DateTime @default(now())
//└ nome    └ Tipo    └ atributos
}

Modificadores e atributos

SintaxeEfeito
Tipo?Campo opcional (a coluna aceita NULL)
Tipo[]Lista (coluna de array no PostgreSQL)
@idChave primária
@@id([a, b])Chave primária composta
@unique / @@unique([a, b])Valor único em um campo / numa combinação de campos
@default(autoincrement())O banco gera 1, 2, 3…
@default(now())O banco grava o instante do insert
@default("member"), @default(true)Padrão literal preenchido pelo banco
@onCreate(uuid())O app (Prisma) gera o valor ao criar. Também aceita uuid(7), cuid(2), ulid(), nanoid() e now()
temporal.CreatedAt / temporal.UpdatedAtTipos prontos para data de criação e de atualização
@map("col") / @@map("tabela")Renomeia a coluna / a tabela no banco
