Glossário

Os termos que usamos no curso, em português, com o equivalente em inglês das docs.

Banco relacional

Tabela (table, relation)
Coleção nomeada de linhas que compartilham as mesmas colunas. [PG] Lição 1
Linha (row, registro)
Uma ocorrência na tabela, por exemplo um usuário. O SQL não garante a ordem das linhas. Lição 1
Coluna (column)
Um atributo da tabela, com tipo de dado fixo. Lição 1
NULL
Ausência de valor numa coluna. Só é permitido se a coluna não for NOT NULL (no Prisma: campo com ?). Lição 1
Chave primária (primary key)
Coluna(s) cujo valor identifica cada linha de forma única. No Prisma: @id. Lição 1
Chave natural (natural key)
Chave que vem do mundo real e é estável, como o código ISO de um país. Lição 1
Chave substituta (surrogate key)
Chave gerada só para identificar a linha (autoincremento, UUID). É o padrão recomendado para dados criados pelo app. Lição 1
Valor padrão (default)
Valor que o banco preenche quando o insert não informa a coluna. No Prisma: @default(...). Lição 1
Restrição de unicidade (unique constraint)
Garante que duas linhas não tenham o mesmo valor numa coluna. No Prisma: @unique. NULLs não contam como repetidos. Violação: erro 23505. Lições 1 e 2
INSERT
Comando SQL que grava uma linha nova. Colunas omitidas recebem o default ou NULL. [PG] Lição 2
Restrição NOT NULL (not-null constraint)
Proíbe NULL na coluna. No Prisma: campo sem ?. Violação: erro 23502. [PG] Lição 2
SQLSTATE
Código de 5 caracteres que identifica um erro do PostgreSQL, como 23505. No Prisma 8: error.sqlState. [PG] Lição 2
Sequência (sequence)
Gerador de números que alimenta o autoincrement(). Valores consumidos nunca voltam, por isso o id pode ter buracos. [PG] Lição 2

Prisma

Contrato (contract, contract.prisma)
Arquivo onde você descreve seus models no Prisma ORM 8. Substitui o schema.prisma do v7 e começa com // use prisma-8. [PSL] Lição 1
Model
Bloco model Nome { ... } do contrato. Vira uma tabela no PostgreSQL. Lição 1
Campo (field)
Uma linha dentro do model, no formato nome Tipo atributos. Um campo escalar vira uma coluna. Lição 1
Campo escalar (scalar field)
Campo que guarda um único valor: String, Int, Boolean, DateTime etc. Lição 1
Atributo (attribute)
Modificador que começa com @ (vale para um campo) ou @@ (vale para o model inteiro). Lição 1
Emitir o contrato (prisma contract emit)
Gera contract.json e contract.d.ts a partir do contrato. São os tipos que o código usa. Rode a cada mudança. [Prisma] Lição 2
db (client)
Objeto criado com postgres({ contract, url }). As consultas ficam em db.orm.public.<Model>: create, all, where(...).update, where(...).deleteAll. Lição 2

Este glossário cresce a cada lição.
